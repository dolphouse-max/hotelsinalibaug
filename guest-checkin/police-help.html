Police Help

Use this page during live police demonstration, training, and day-to-day record lookup. Switch between English and Marathi at the top.

This section is for police officers who need quick access to guest data, proof review, hotel-wise filtering, and audit-backed search across one or many hotels.

1. Initial Police Setup

1. Open Police Dashboard and log in with the police email and password given by superadmin.

2. Enter the officer name once on the dashboard so it is reused in police pages and audit logs.

3. Open Police Main Page and save the hotel filter and date range if you are checking one hotel repeatedly.

4. Use All Hotels Guest Search when you need to search across every registered hotel by name, mobile number, or car number.

5. Use Police Console only when proof review or guest-level audited access is required.

2. What Each Police Page Does

Police Dashboard

Use this login page to sign in, save officer name, change password, and send password reset mail if needed.

Police Main Page

This is the central page to save one hotel, officer name, and date range. All other police reports reuse those saved filters on the same device.

All Hotels Guest Search

Search all hotel guest records in one place by guest name, mobile number, or car number. This is the fastest page for general enquiry.

Police Console

Use this when police need controlled access to one guest or hotel set. It logs the officer name and guest access for audit purposes and can open proof documents.

Hotel Details

Shows hotel identity, contact details, room count, and hotel profile information.

Current Guests

Shows who is currently staying in the selected hotel.

Guest Register

Shows guest history for the selected hotel and date range, with search filters and proof access.

Staff Register

Shows hotel staff names, role, phone number, address, and current status.

Police Access History

Shows audit rows of which officer opened which guest records and when.

4. Search and Filter Tips

Use hotel filter when the enquiry is about one specific hotel.

Use All Hotels Guest Search for broader checking across all hotels.

Use mobile number for fastest exact guest lookup.

Use car number when guest name spelling is uncertain.

Use date filters on Guest Register and Access History pages to reduce clutter and speed up results.

5. Security and Audit Control

Police access is controlled by police login created by superadmin.

Guest proof review happens inside the app, not by open browsing of hotel Google Drive.

Proof access and guest lookup through Police Console can be logged against officer name and time.

The system is designed to give structured hotel-owned data with controlled police access.

1. पोलिसांसाठी सुरुवातीची सेटअप

1. Police Dashboard उघडा आणि superadmin ने दिलेल्या police email व password ने लॉगिन करा.

2. Officer name एकदाच भरा. तो पुढे police pages आणि audit logs मध्ये वापरला जाईल.

3. Police Main Page वर hotel आणि date range save करा, जर एखाद्या एका हॉटेलची वारंवार चौकशी करायची असेल.

4. अनेक हॉटेलमध्ये एकाच वेळी शोध घ्यायचा असल्यास All Hotels Guest Search वापरा.

5. Guest proof किंवा audited guest-level access आवश्यक असल्यास Police Console वापरा.

4. Search आणि Filter वापरण्याच्या टिप्स

एखाद्या विशिष्ट hotel बद्दल चौकशी असेल तर hotel filter वापरा.

अनेक hotel मध्ये शोध घ्यायचा असेल तर All Hotels Guest Search वापरा.

Exact guest शोधण्यासाठी mobile number सर्वात जलद असतो.

Guest name spelling नक्की नसेल तर car number वापरा.

Guest Register आणि Access History वर date filters वापरल्यास results कमी होतात आणि page जलद चालतो.

5. सुरक्षा आणि Audit नियंत्रण

Police access हा superadmin ने तयार केलेल्या police login वर आधारित असतो.

Guest proof review हे app च्या आत होते. Hotel च्या Google Drive ची open browsing दिली जात नाही.

Police Console मधून guest lookup आणि proof access officer name व वेळेसह log होऊ शकतो.

ही system हॉटेलचे data त्यांच्या मालकीत ठेवून police साठी controlled access देण्यासाठी बनवली आहे.
